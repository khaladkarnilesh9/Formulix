# Country Boundaries

`countries-110m.json` is the unmodified world-atlas 2 dataset, derived from
Natural Earth 4.1.0 Admin 0 boundaries at 1:110m. The redistribution license
is included in `LICENSE.txt`. Boundaries are cartographic references, not
claims of jurisdiction, regulatory recognition, or product approval.

Source: https://github.com/topojson/world-atlas
