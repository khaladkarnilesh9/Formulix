# Scientific Banner Assets

These seven original AI-generated conceptual backgrounds were created for Formulix.
They are decorative subject-area imagery, not evidence of an actual product, company,
chemical identity, laboratory process, patent, or regulatory approval.

The application renders all headings, controls, data and scientific structures as live
React components. No screenshot text, product packaging, company logo, notification count,
or sample metric from the supplied UI reference is embedded in these assets.

Images are JPEG-optimized at quality 85. The optional Windows preparation utility is
`scripts/prepare-scientific-image.ps1`; original generated files remain unmodified.
